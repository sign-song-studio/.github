# Sign Song Studio

我们维护手语歌智能工坊，帮助老师查词、讨论歌词转写、制作手势图解讲义。

- [查看公开版及正式包状态](https://github.com/LuckytoeUSTC/sign-song-agent-public)
- 科大手语组成员及参与手语教学的校内师生，可按公开版首页说明申请访问。已获邀请的老师可从[校内仓库](https://github.com/sign-song-studio/sign-song-agent)下载。
- 通用问题可在[公开 Issues](https://github.com/LuckytoeUSTC/sign-song-agent-public/issues)反馈。涉及校内资料，请在校内仓库讨论或私聊联星老师。
