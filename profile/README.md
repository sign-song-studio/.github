# 手语歌智能工坊 · Sign Song Studio

为手语老师准备的备课工具。可以查手语词、讨论歌词转写，并制作带手势图解的 Word 讲义。

**[查看公开版](https://github.com/LuckytoeUSTC/sign-song-agent-public) · [申请校内完整版](https://github.com/LuckytoeUSTC/sign-song-agent-public) · [反馈使用问题](https://github.com/LuckytoeUSTC/sign-song-agent-public/issues)**

### 校内老师

已获邀请的老师可以直接进入[校内仓库](https://github.com/sign-song-studio/sign-song-agent)。科大手语组成员及参与手语教学的校内师生，可以在公开版首页查看申请方式。

### 一起维护

欢迎熟悉工坊备课流程、愿意试用或审核改动的老师参与。详情见[校内维护招募](https://github.com/orgs/sign-song-studio/discussions/8)。涉及校内讲义的反馈，请在校内仓库讨论或私聊联星老师。
